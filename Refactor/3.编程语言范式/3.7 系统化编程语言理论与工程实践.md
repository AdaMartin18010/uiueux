## 1. 概述 / Overview

系统化编程语言理论与工程实践建立语言设计、实现与评估的一体化方法论。

## 2. 编程语言理论（节选）

- 语法/语义/类型理论
- 静态语义、操作语义、类型安全

## 3. 工程实践体系（节选）

- 编译器工程：前端/中端/后端、优化Pass
- 运行时系统：内存管理、并发模型

## 4. 形式化语言分析（节选）

- 形式化语义：指称/操作/公理/代数
- 类型系统分析：健全性、完备性、可判定性、复杂度
- 验证：编译器正确性、标准符合性
